## Authority

Only the E8-normalized general patterns inside [framework/AI_SDLC_DPF.md](framework/AI_SDLC_DPF.md) are normative when selected for application.

Reference Architecture, Reference Process, Primary Application Profile and Application Guide have respectively reference, profile and informative authority within their stated boundaries. They do not acquire the authority of the DPF.

The Reference Process/Application Guide identities in this assembly are recovered through the Work Kit assembly version, component path and exact manifest hash; they do not receive an invented independent semantic version.

The controlled release is not:

- an Organization LPF;
- a process for a concrete project;
- a standard;
- proof of regulatory compliance;
- assurance for a concrete product;
- a ready-made agent configuration;
- a mandatory V-cycle;
- a mandatory model-driven architecture.

An organization or project must separately determine applicability, roles, tools, thresholds, evidence and local authority.
